# Contributing

Open an issue describing the proposed contract or behaviour change, with a small synthetic reproduction.

Use `feature/` branches based on `develop`. Submit pull requests to `develop` and assign Tony Chemit (`ultreiaio`).

Keep runtime dependencies minimal. Tests and examples must work offline without credentials or domain data.

Edit YAML artifacts once. Edit `README.Rmd` and roxygen comments, then regenerate their outputs.

Run the commands in [DEVELOPMENT.md](DEVELOPMENT.md) before requesting review.

Add behavioural tests for contract changes and describe compatibility in NEWS.

By contributing, you agree to license your contributions under LGPL-2.1.
